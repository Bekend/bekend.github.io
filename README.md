## 🌐 مراحل استقرار (Deploy) ۱۰۰٪ رایگان روی GitHub Pages و اتصال دامنه `shahab-hb.ir`

### مرحله ۱: ساخت ریپوزیتوری در گیت‌هاب
1. وارد حساب گیت‌هاب خودت شو: `https://github.com/Bekend`
2. یک ریپوزیتوری جدید بساز به یکی از این دو نام:
   - **حالت اول (پیشنهادی):** `bekend.github.io` (در این حالت پورتفولیو به صورت مستقیم روی روت گیت‌هاب شما می‌نشیند).
   - **حالت دوم:** `resume` یا هر اسم دلخواه دیگری.
3. حالت دسترسی را روی **Public** بگذار.

### مرحله ۲: آپلود و پوش کردن کدها
در ترمینال، در پوشه `c:\Users\shahab\resume` دستورات زیر را اجرا کن:
```bash
git add .
git commit -m "feat: initial release of modern bilingual engineering portfolio"
git remote add origin https://github.com/Bekend/bekend.github.io.git
git push -u origin main
```
*(اگر نام ریپوزیتوری را چیز دیگری گذاشتی، آدرس بالا را متناسب با آن تغییر بده).*

### مرحله ۳: فعال‌سازی GitHub Pages
1. در صفحه ریپوزیتوری در گیت‌هاب، به تب **Settings** برو.
2. از منوی سمت چپ روی **Pages** کلیک کن.
3. در بخش **Build and deployment**، گزینه **Source** را روی `Deploy from a branch` بگذار و برنچ را `main` و پوشه را `/ (root)` انتخاب کن و Save را بزن.
4. در پایین همان صفحه در قسمت **Custom domain** مطمئن شو که `shahab-hb.ir` نوشته شده باشد (فایل `CNAME` به صورت خودکار این را تنظیم می‌کند).
5. تیک گزینه **Enforce HTTPS** را بزن تا گواهینامه امنیتی SSL فعال شود.
